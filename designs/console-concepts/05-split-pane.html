05 · Split Pane Workbench

Idea: a desktop-mail style window: one toolbar row (Capture · mark tool · destination · send mode), a numbered list on the left and a large review pane on the right. This is the current layout taken to a comfortable width. Settings open as a modal with a category sidebar, so each group shows on one screen.

Size: 760 × 520 (min ≈ 640 × 420). Trade-offs: best for reviewing many annotations, but it covers more of the app being annotated; it is too wide to dock usefully, so it falls back to the stacked layout below ≈ 560px.
