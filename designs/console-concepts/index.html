Annotate Console — 10 design concepts

Static, self-contained mockups. Every concept covers the real feature set: Capture with countdown, Area / Freehand marks, Discard all, Send with count, Send as (Follow-up / Queued), destination session, notice line, drafts with Retake / Reuse / Remove and an editable selected note, privacy warning, and reorganised Settings (shortcut recorder, global toggle, countdown, capture mode, batch maximum, default send as).
