Settings

Shortcut

Click the field and press the key combination to use, e.g. ⌘/Ctrl+Shift+A. Backspace clears it to use the launch default shown in the field. The shortcut starts capture immediately.

On: the shortcut starts annotation from anywhere in the operating system. Off: it only works while the Annotate Console is focused.

Capture

Wait before Capture or Retake so you can reopen a menu. Set 0 for no delay. The keyboard shortcut always captures immediately.

Live marks the app without freezing, then captures it. Preserved freezes the desktop before marking to keep menus. Other desktops use their native live capture.

Batch

Default: 8; range 1–12. The 24 MiB transport limit still applies. Existing drafts are never removed by settings.

Appearance

Timeline feed is a narrow panel that docks to a screen edge; double-click an annotation to open it beside the panel. Command pill is a compact floating bar that opens into a tray.
